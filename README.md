# 🥐✨ Bakery Chatbot Agent - n8n Workflow

> *From idea to reality: I created my own Bakery Chatbot Agent in n8n — no code, just creativity and workflow magic!*

## 🎯 What It Does

This intelligent chatbot agent handles everything a bakery needs - from taking orders to managing inventory, all automated with n8n!

## 🍞 Project Goals

- **Automate orders** and reduce manual work ⚡
- **Display real-time menu updates** 🍩🥧
- **Handle FAQs professionally** ⏰🚚
- **Manage out-of-stock items automatically** ❌
- **Optional AI-powered casual replies** 🤖💬

- Take new orders
- Custom cake requests 🎂
- Special dietary requirements (gluten-free, vegan)
- Order confirmation messages

### 🔄 Inventory Automation
- Auto-update out-of-stock items ❌

- Handle complex queries
